# Welcome to Turbo MVP

Este é seu primeiro note no **Turbo MVP**!

## 🚀 Funcionalidades

- ✅ **File Watcher**: Adicione arquivos `.md` na pasta `./notes` e eles serão automaticamente ingeridos
- ✅ **Auto-Tags**: Use `#tags` no conteúdo para categorização automática
- ✅ **Wikilinks**: Use `[[links]]` para conectar notas
- ✅ **Grafo de Conhecimento**: Visualize conexões entre suas notas via API

## 📝 Como Usar

1. Inicie o servidor: `npm run dev`
2. Acesse a API: `http://localhost:3000`
3. Adicione mais notas na pasta `./notes`
